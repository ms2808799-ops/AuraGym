AuraGym

AuraGym is a modern, responsive web application designed for a fitness gym. It features an interactive user interface, membership checkout options, and a clean layout for gym enthusiasts.

Project Structure

AuraGym/
│
├── images/             # Image assets used across the site
├── webfonts/           # Font files (e.g., FontAwesome webfonts)
├── all.min.css         # Icon or utility library CSS stylesheet
├── checkout.html       # Membership checkout and payment page
├── index.html          # Main landing page
├── main.css            # Custom styling for the project
└── main.js             # JavaScript functionality and interactivity


Technologies Used

HTML5: Semantic page structure

CSS3 & Custom Styles: Styling, layouts, and responsive design

JavaScript: Dynamic features and user interactions

FontAwesome: Icons (all.min.css and webfonts)

Getting Started

Since this is a pure frontend project built with HTML, CSS, and JavaScript, it does not require any package managers like npm, node.js, or backend servers to run.

Installation & Running

Clone or download the repository:

git clone https://github.com/your-username/AuraGym.git


Open the project folder in your code editor (such as Visual Studio Code).

To view and run the project locally:

Open the index.html file directly in your web browser, OR

Use a live server extension (like Live Server in VS Code) for the best development experience with live reloading.
